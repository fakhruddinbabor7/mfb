# Mohammad Fakhruddin Babar — Personal Website

Plain HTML/CSS/JS portfolio for GitHub Pages. No build step.

## Files

| File | What it is |
|---|---|
| `index.html` | Home: intro, skills, selected projects, experience, recent papers, contact |
| `research.html` | All research projects with results and paper links |
| `publications.html` | Full publication list |
| `experience.html` | Work history, education, awards |
| `news.html` | Milestones (copy one `<li>` to the top to add an update) |
| `gallery.html` | Photos |
| `contact.html` | Contact links |
| `styles.css` | The only stylesheet (colors in `:root` at the top) |
| `script.js` | Mobile menu + footer year |

## Before publishing

1. Put your CV at `assets/Babar_CV.pdf` (the "Download CV" buttons link there).
2. Optional: add your programming languages and tools in `index.html`.
   Search for `Languages & tools` and uncomment the block.

## Publish

1. Replace the repository contents with this folder.
2. Commit and push to `main`.
3. **Settings → Pages**: Deploy from a branch → `main` / `(root)`.
